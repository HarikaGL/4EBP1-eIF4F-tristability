# 4E-BP1 / eIF4F tristability model

Code, model files and data for the article

> G L Harika and Krishnamachari Sriram. *Staged 4E-BP1 phosphorylation creates two switches in series that give eIF4F memory.* Submitted to npj Systems Biology and Applications (2026).

Archived version: Zenodo, https://doi.org/10.5281/zenodo.24357091 (see `CITATION.cff`).
License: MIT (see `LICENSE`). Contact: Krishnamachari Sriram (sriramk@iiitd.ac.in).

The large result files of our own runs (`MATLAB/Results/M10_*.mat`, `M11_*.mat`, `M12_*.mat`, about 150 MB) are in the Zenodo deposit only; every one of them is regenerated by its script.


Everything needed to regenerate the results of the manuscript (npj Systems Biology and Applications version), in MATLAB, plus the model in SBML and XPPAUT formats.
No toolbox is needed. The Parallel Computing Toolbox is used when present (the long loops are `parfor`); without it they run as ordinary loops. Everything also runs in GNU Octave (tested with 8.4), but the Gillespie simulations (M11, M12) are many times slower there; use MATLAB for them.

## How to run

Open MATLAB in the folder `MATLAB/` and run `run_all` (all compute scripts in order), or run any script in `MATLAB/compute/` on its own; each script adds the model folder to the path itself. To redraw a figure, run for example `Fig03_three_states` in `MATLAB/figures/`.

Every long script has a quick mode for testing: set `QUICK = true;` before running it.

Note on `Results/M13_log.txt`: it was printed by our run before a correction of the part-B summary (`model/p4e_m13_report.m`): MATLAB's `max` ignores NaN, so sets that switched on but had not switched off within 24 h were counted as "switching both ways". The saved switching times were not affected. With the corrected report (to reprint it from the saved files, in `MATLAB/` run `setup_p4e; for n = {'fold2','fold3','fold10','exp'}, S = load(fullfile('Results', ['M13_B_' n{1} '.mat'])); p4e_m13_report(n{1}, S.b); end`) the numbers are those of Section 2.8: 12 194, 5 998 and 640 sets switch both ways within 24 h in the <=2-, <=3- and <=10-fold ensembles; 358 (2.8%), 662 (10.1%) and 76 (9.2%) within 60 min.

The Gillespie simulations are exact (every one of the 44 reaction channels is simulated, no approximation), so a 20-h replicate contains 1.5 x 10^8 to 6 x 10^8 reaction events. With a different random seed the individual trajectories differ, but the numbers reported (fractions of replicates, medians, ranges) agree within sampling error.

## Units and conventions

Concentrations in nM, first-order constants in s^-1, second-order constants in nM^-1 s^-1, time in s (h in the outputs). R1-R22 as in Supplementary Note 1 and Methods 4.1. The species order of the full ODEs is
`[e4F BPe4Epp BPe4Ep4 C1 BPe4Ep C2 C3 C4 C5 BPe4Ep3 C6 C7 C8 BPp4 e4GE e4GA BPe4E]`; the free pools kin, P, e4E, BP, e4G and e4A follow from the six conservation relations.
